# Faro - Sistema de Seguridad Personal y Alerta SOS

## Propósito
Faro es una Aplicación Web Progresiva (PWA) Offline-First diseñada para brindar seguridad física personal, respuesta rápida, y geolocalización de emergencias ("Tu Seguridad, Tu Luz"). Su enfoque principal es la prevención de riesgos y la alerta inmediata a contactos de confianza (Faros).

## Stack Técnico
- **Frontend:** Vanilla JS, HTML5, CSS3 (Cyber-Obsidian Theme).
- **Arquitectura:** PWA Offline-First (Service Worker Cache).
- **Mapas:** ESRI World Dark Gray Canvas via Leaflet.js.
- **Persistencia:** LocalStorage (Zero-Leakage).
- **Notificaciones:** Integración directa con WhatsApp (Auto-despacho de coordenadas).

## Despliegue
Desplegado automáticamente vía GitHub Pages y Cloudflare Pages. No requiere API Keys externas.
